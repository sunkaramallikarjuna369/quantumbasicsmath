Quantum Superposition

The Heart of Quantum Computing - Being in Multiple States Simultaneously

What is Superposition?

Superposition is the fundamental principle that allows a qubit to exist in a combination of |0⟩ and |1⟩ states simultaneously. Unlike a classical bit that must be either 0 or 1, a qubit in superposition is described by complex amplitudes α and β, where the state is |ψ⟩ = α|0⟩ + β|1⟩. The probabilities of measuring 0 or 1 are |α|² and |β|² respectively, and they must sum to 1 (normalization condition).

|ψ⟩ = α|0⟩ + β|1⟩    where    |α|² + |β|² = 1

The Equal Superposition State |+⟩

Mathematical Representation

|+⟩ = 1/√2 (|0⟩ + |1⟩)
= 1/√2 [ 1 1 ] ≈ [ 0.707 0.707 ]

Both amplitudes are equal: 1/√2 ≈ 0.707

Probability Distribution

|0⟩
50%
|1/√2|² = 1/2
|1⟩
50%
|1/√2|² = 1/2

Normalization

Why Normalize?

The normalization condition |α|² + |β|² = 1 ensures that the total probability of all possible measurement outcomes equals 100%. Without normalization, probabilities wouldn't make physical sense.

Normalization Process

# Unnormalized state psi = ket0 + ket1 print(psi) # Output: [[1], [1]] # Check norm (should be 1 for valid state) norm = np.linalg.norm(psi) print(norm) # Output: 1.414... (√2) # Normalize the state psi_normalized = psi / norm # OR equivalently: psi = (1/np.sqrt(2)) * (ket0 + ket1)

Python Implementation

import numpy as np # Define basis states ket0 = np.array([[1], [0]], dtype=complex) ket1 = np.array([[0], [1]], dtype=complex) # Create superposition (unnormalized first) psi_unnorm = ket0 + ket1 print("Unnormalized:", psi_unnorm.flatten()) # Output: [1.+0.j 1.+0.j] # Normalize to create valid quantum state psi = (1/np.sqrt(2)) * (ket0 + ket1) print("Normalized |+⟩:", psi.flatten()) # Output: [0.707+0.j 0.707+0.j] # Verify normalization norm = np.linalg.norm(psi) print("Norm:", norm) # Output: 1.0 # Calculate measurement probabilities prob_0 = np.abs(psi[0])**2 prob_1 = np.abs(psi[1])**2 print(f"P(0) = {prob_0[0]:.3f}, P(1) = {prob_1[0]:.3f}") # Output: P(0) = 0.500, P(1) = 0.500
