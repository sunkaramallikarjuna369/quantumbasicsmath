Inner Product ⟨φ|ψ⟩

Measuring Overlap Between Quantum States

What is the Inner Product?

The inner product (also called bracket or dot product) measures the "overlap" between two quantum states. For states |φ⟩ and |ψ⟩, the inner product ⟨φ|ψ⟩ is computed as φ†ψ (conjugate transpose of φ times ψ). The result is a complex number whose squared magnitude |⟨φ|ψ⟩|² gives the probability of measuring |φ⟩ when the system is in state |ψ⟩.

⟨φ|ψ⟩ = φ†ψ = Σᵢ φᵢ* ψᵢ

Computing Inner Products

⟨0|0⟩ = 1 (Orthonormal)

[1 0] × [1] = 1×1 + 0×0 = 1
        [0]

A state has perfect overlap with itself

⟨0|1⟩ = 0 (Orthogonal)

[1 0] × [0] = 1×0 + 0×1 = 0
        [1]

Orthogonal states have zero overlap

⟨0|+⟩ = 1/√2 (Partial Overlap)

[1 0] × [1/√2] = 1×(1/√2) + 0×(1/√2)
        [1/√2]
= 1/√2 ≈ 0.707

|⟨0|+⟩|² = 1/2 = 50% probability

⟨+|-⟩ = 0 (Orthogonal)

[1/√2 1/√2] × [ 1/√2]
               [-1/√2]
= 1/2 - 1/2 = 0

|+⟩ and |-⟩ are orthogonal!

Geometric Interpretation

Vectors on Bloch Sphere

Inner product relates to the angle between state vectors

Probability vs Angle

|⟨φ|ψ⟩|² = cos²(θ/2) where θ is the angle on Bloch sphere

Physical Meaning

Probability Amplitude: ⟨φ|ψ⟩ is the probability amplitude for transitioning from |ψ⟩ to |φ⟩.

Measurement Probability: |⟨φ|ψ⟩|² is the probability of measuring the system in state |φ⟩ when it's prepared in state |ψ⟩.

Orthogonality: If ⟨φ|ψ⟩ = 0, the states are orthogonal (perfectly distinguishable).

Normalization: ⟨ψ|ψ⟩ = 1 for any valid quantum state (total probability = 100%).

Python Implementation

import numpy as np # Define basis states ket0 = np.array([[1], [0]], dtype=complex) ket1 = np.array([[0], [1]], dtype=complex) # Define |+⟩ and |-⟩ states ket_plus = (1/np.sqrt(2)) * (ket0 + ket1) ket_minus = (1/np.sqrt(2)) * (ket0 - ket1) # Compute inner products using conjugate transpose phi = ket0 psi = ket_plus inner = phi.conj().T @ psi # ⟨φ|ψ⟩ = φ†ψ print("⟨0|+⟩ =", inner[0,0]) # Output: (0.707+0j) # Probability of measuring |0⟩ in state |+⟩ prob = np.abs(inner)**2 print("|⟨0|+⟩|² =", prob[0,0]) # Output: 0.5 # Verify orthogonality of |+⟩ and |-⟩ inner_pm = ket_plus.conj().T @ ket_minus print("⟨+|-⟩ =", inner_pm[0,0]) # Output: 0j (orthogonal!) # Verify normalization norm = ket_plus.conj().T @ ket_plus print("⟨+|+⟩ =", norm[0,0]) # Output: (1+0j)
