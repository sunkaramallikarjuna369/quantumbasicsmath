Outer Product |φ⟩⟨ψ|

Building Operators from Quantum States

What is the Outer Product?

The outer product of two states |φ⟩ and |ψ⟩ creates a matrix (operator). Unlike the inner product ⟨φ|ψ⟩ which gives a scalar, the outer product |φ⟩⟨ψ| gives a matrix that can act on other states. This is fundamental for constructing projection operators, density matrices, and quantum gates.

|φ⟩⟨ψ| = φ × ψ†    (column × row = matrix)

Inner vs Outer Product

Property Inner Product ⟨φ|ψ⟩ Outer Product |φ⟩⟨ψ|
Result Type Scalar (complex number) Matrix (operator)
Dimensions 1×n × n×1 = 1×1 n×1 × 1×n = n×n
Physical Meaning Overlap/probability amplitude Projection/transformation operator
Example ⟨0|1⟩ = 0 |0⟩⟨1| = [[0,1],[0,0]]

Projection Operators

A projection operator P = |ψ⟩⟨ψ| projects any state onto |ψ⟩. Key properties: P² = P (applying twice is same as once), P† = P (Hermitian), and Tr(P) = 1.

Completeness Relation

|0⟩⟨0| + |1⟩⟨1| = I

Sum of all projectors = Identity matrix

Building Gates from Outer Products

Quantum gates can be constructed as sums of outer products. For example:

X Gate (NOT)

X = |0⟩⟨1| + |1⟩⟨0|

Python Implementation

import numpy as np # Define basis states ket0 = np.array([[1], [0]], dtype=complex) ket1 = np.array([[0], [1]], dtype=complex) bra0 = ket0.conj().T bra1 = ket1.conj().T # Compute outer products outer_00 = ket0 @ bra0 # |0⟩⟨0| outer_11 = ket1 @ bra1 # |1⟩⟨1| outer_01 = ket0 @ bra1 # |0⟩⟨1| outer_10 = ket1 @ bra0 # |1⟩⟨0| print("|0⟩⟨0| =\n", outer_00) # Output: [[1 0] # [0 0]] print("|0⟩⟨1| =\n", outer_01) # Output: [[0 1] # [0 0]] # Build X gate from outer products X = outer_01 + outer_10 print("X gate =\n", X) # Output: [[0 1] # [1 0]] # Verify completeness: |0⟩⟨0| + |1⟩⟨1| = I I = outer_00 + outer_11 print("Identity =\n", I) # Output: [[1 0] # [0 1]] # Projection: P|ψ⟩ projects onto |0⟩ psi = (1/np.sqrt(2)) * (ket0 + ket1) # |+⟩ projected = outer_00 @ psi print("P|+⟩ =", projected.flatten()) # Output: [0.707 0] (unnormalized |0⟩)
