Tensor Product ⊗

Combining Quantum Systems - Building Multi-Qubit States

Notation Guide - Read This First!

⊗
"Tensor product" (also called Kronecker product) - Combines two quantum systems into one larger system.
|00⟩
"Ket zero-zero" - A 2-qubit state where both qubits are 0. Same as |0⟩ ⊗ |0⟩ or |0⟩|0⟩
|ψ⟩|φ⟩
Shorthand for |ψ⟩ ⊗ |φ⟩ - The tensor product of two states.
2n
Dimension formula - n qubits need a vector of size 2n. 1 qubit = 2, 2 qubits = 4, 3 qubits = 8, etc.

What is the Tensor Product?

Simple Explanation: The tensor product combines two separate quantum systems into one joint system.
Think of it as: "Scale and Stack"
  1. Take each element of the first vector
  2. Multiply it by the ENTIRE second vector
  3. Stack all the results into one big vector
Why We Need It: To describe 2 qubits, we need 4 possible outcomes: |00⟩, |01⟩, |10⟩, |11⟩
1 qubit: 2 amplitudes 2 qubits: 4 amplitudes 3 qubits: 8 amplitudes n qubits: 2n amplitudes

Entanglement: States That Can't Be Factored

Important! Some 2-qubit states CANNOT be written as |a⟩ ⊗ |b⟩ for any single-qubit states. These are called entangled states.

Separable State (NOT entangled)

|01⟩ = |0⟩ ⊗ |1⟩

Can be factored into two separate qubits.
Qubit 1 is definitely |0⟩
Qubit 2 is definitely |1⟩

Bell State (ENTANGLED)

|Φ⁺⟩ = (|00⟩ + |11⟩)/√2

CANNOT be factored!
Neither qubit has a definite value.
But they're perfectly correlated.

? Why can't the Bell state be factored?

If |Φ⁺⟩ = |a⟩ ⊗ |b⟩ for some |a⟩ = [α, β] and |b⟩ = [γ, δ], then:

|00⟩ amplitude: α×γ = 1/√2
|01⟩ amplitude: α×δ = 0
|10⟩ amplitude: β×γ = 0
|11⟩ amplitude: β×δ = 1/√2

Problem: If α×δ = 0, then either α=0 or δ=0.
But if α=0, then α×γ can't equal 1/√2!
Contradiction! So no such |a⟩, |b⟩ exist.

Tensor Product of Operators

To apply a gate to just ONE qubit in a multi-qubit system, use tensor products with the identity matrix I.

H ⊗ I

Apply Hadamard to first qubit only

First qubit: H (creates superposition)
Second qubit: I (does nothing)

I ⊗ H

Apply Hadamard to second qubit only

First qubit: I (does nothing)
Second qubit: H (creates superposition)
