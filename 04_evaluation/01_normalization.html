Normalization & Probability

Ensuring Valid Quantum States

The Normalization Condition

A valid quantum state must be normalized - the sum of squared magnitudes of all amplitudes must equal 1. This ensures that the total probability of all possible measurement outcomes is 100%. For a state |ψ⟩ = α|0⟩ + β|1⟩, we require |α|² + |β|² = 1.

⟨ψ|ψ⟩ = Σᵢ |αᵢ|² = 1    (Normalization Condition)

Probability Distribution

Born Rule: Probability from Amplitude

The Born rule states that the probability of measuring a particular outcome is the squared magnitude of the corresponding amplitude. This is why we need complex numbers - the phase affects interference but not individual probabilities.

P(outcome i) = |⟨i|ψ⟩|² = |αᵢ|²

Amplitude vs Probability

Complex Amplitude Example

|ψ⟩ = (1+i)/2 |0⟩ + (1-i)/2 |1⟩
Both have |amplitude|² = 0.5

Normalizing a State

Before Normalization

|ψ⟩ = |0⟩ + |1⟩
||ψ|| = √2 ≠ 1

After Normalization

|ψ⟩ = (|0⟩ + |1⟩)/√2
||ψ|| = 1

Python Implementation

import numpy as np # Define an unnormalized state psi_unnorm = np.array([[1], [1]], dtype=complex) # Calculate the norm norm = np.linalg.norm(psi_unnorm) print("Norm before:", norm) # Output: 1.414... (√2) # Normalize the state psi = psi_unnorm / norm print("Normalized state:", psi.flatten()) # Output: [0.707 0.707] # Verify normalization norm_after = np.linalg.norm(psi) print("Norm after:", norm_after) # Output: 1.0 # Calculate probabilities using Born rule prob_0 = np.abs(psi[0])**2 prob_1 = np.abs(psi[1])**2 print(f"P(0) = {prob_0[0]:.4f}") # Output: 0.5 print(f"P(1) = {prob_1[0]:.4f}") # Output: 0.5 print(f"Total = {prob_0[0] + prob_1[0]:.4f}") # Output: 1.0 # Complex amplitude example psi_complex = np.array([[(1+1j)/2], [(1-1j)/2]], dtype=complex) print("Complex state:", psi_complex.flatten()) print("P(0) =", np.abs(psi_complex[0])**2) # 0.5 print("P(1) =", np.abs(psi_complex[1])**2) # 0.5
