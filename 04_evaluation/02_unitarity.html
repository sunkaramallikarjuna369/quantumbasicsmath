Unitarity

Why Quantum Gates Must Be Reversible

What is Unitarity?

A matrix U is unitary if U†U = UU† = I, where U† is the conjugate transpose (Hermitian adjoint). All quantum gates must be unitary because this ensures: (1) probability is preserved, (2) the operation is reversible, and (3) quantum information is never lost. This is a fundamental requirement of quantum mechanics.

U†U = UU† = I    (Unitarity Condition)

Verifying Unitarity

Hadamard Gate

H = 1/√2 [1   1]
           [1 -1]
H†H = I

Pauli-X Gate

X = [0 1]
    [1 0]
X†X = I

Pauli-Y Gate

Y = [0 -i]
    [i  0]
Y†Y = I

Pauli-Z Gate

Z = [1  0]
    [0 -1]
Z†Z = I

Why Unitarity Matters

Probability Preservation

||U|ψ⟩|| = ||ψ|| for any unitary U
Total probability stays at 100%

Reversibility

U⁻¹ = U† always exists
Every quantum operation can be undone

Non-Unitary Operations

Measurement is the only non-unitary operation in quantum computing. It collapses the superposition and is irreversible - you cannot "unmeasure" a qubit. This is why measurement is typically done only at the end of a quantum algorithm.

Measurement is NOT Unitary

Measurement destroys superposition
Information is lost → Not reversible

Python Implementation

import numpy as np # Define gates H = (1/np.sqrt(2)) * np.array([[1, 1], [1, -1]], dtype=complex) X = np.array([[0, 1], [1, 0]], dtype=complex) Y = np.array([[0, -1j], [1j, 0]], dtype=complex) Z = np.array([[1, 0], [0, -1]], dtype=complex) I = np.eye(2, dtype=complex) def is_unitary(U): """Check if matrix U is unitary: U†U = I""" product = U.conj().T @ U return np.allclose(product, I) # Verify all gates are unitary print("H is unitary:", is_unitary(H)) # True print("X is unitary:", is_unitary(X)) # True print("Y is unitary:", is_unitary(Y)) # True print("Z is unitary:", is_unitary(Z)) # True # Show U†U = I for Hadamard print("H†H =\n", H.conj().T @ H) # Output: [[1 0] # [0 1]] # Verify probability preservation ket0 = np.array([[1], [0]], dtype=complex) psi = H @ ket0 # Apply H to |0⟩ norm_before = np.linalg.norm(ket0) norm_after = np.linalg.norm(psi) print(f"Norm before: {norm_before}") # 1.0 print(f"Norm after: {norm_after}") # 1.0 # Verify reversibility: H⁻¹ = H† H_inv = H.conj().T print("H⁻¹ = H†?", np.allclose(H_inv, H)) # True (H is Hermitian)
