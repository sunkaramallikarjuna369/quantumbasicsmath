Building Quantum Circuits with Multiple Qubits

From Single to Multiple Qubits

Real quantum computers use multiple qubits working together. The state space grows exponentially: n qubits have 2ⁿ basis states. A 2-qubit system has 4 basis states (|00⟩, |01⟩, |10⟩, |11⟩), a 3-qubit system has 8, and so on. This exponential growth is the source of quantum computing's power.

n qubits → 2ⁿ dimensional Hilbert space

Applying Gates to Specific Qubits

To apply a gate to only one qubit in a multi-qubit system, we use tensor products with identity matrices. For example, to apply H to qubit 1 in a 2-qubit system: H⊗I. To apply X to qubit 2: I⊗X.

H ⊗ I (H on qubit 1)

(H⊗I)|00⟩ = |+0⟩ = (|00⟩+|10⟩)/√2

I ⊗ H (H on qubit 2)

(I⊗H)|00⟩ = |0+⟩ = (|00⟩+|01⟩)/√2

def kron_all(matrices):
    """
    Compute Kronecker product of a list of matrices.
    Used to build multi-qubit operators like H^{⊗n}.
    """
    result = np.array([[1]], dtype=complex)
    for m in matrices:
        result = np.kron(result, m)
    return result

def H_n(n):
    """
    Hadamard on n qubits: H ⊗ H ⊗ ... ⊗ H
    """
    return kron_all([H] * n)
