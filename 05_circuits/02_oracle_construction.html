What is a Quantum Oracle?

A quantum oracle (also called a black box) is a unitary operator that encodes a classical function f(x) into a quantum circuit. The oracle implements the transformation |x⟩|y⟩ → |x⟩|y⊕f(x)⟩, where ⊕ is XOR. This allows quantum algorithms to query the function in superposition, evaluating f(x) for all inputs simultaneously.

Uf|x⟩|y⟩ = |x⟩|y ⊕ f(x)⟩

Phase Kickback

When the ancilla qubit is in state |-⟩ = (|0⟩-|1⟩)/√2, the oracle creates a phase kickback. Instead of flipping the ancilla, the phase (-1)^f(x) is "kicked back" to the input register. This is the key mechanism that allows Deutsch-Jozsa to work.

Uf|x⟩|-⟩ = (-1)f(x)|x⟩|-⟩

Phase Kickback Visualization

Why It Works

When y = |-⟩ = (|0⟩-|1⟩)/√2:

|y⊕0⟩ = |y⟩ = |-⟩

|y⊕1⟩ = |NOT y⟩ = -|-⟩

So: |x⟩|y⊕f(x)⟩ = (-1)^f(x)|x⟩|-⟩

The phase moves to the input qubit!

Oracle Matrix Representation

f(x) = 0 (Identity)

Uf = I (does nothing)

f(x) = 1 (X on ancilla)

Uf = I⊗X

f(x) = x (CNOT)

Uf = CNOT

def oracle_Uf(n, f):
    """
    Build the oracle matrix Uf for n input qubits + 1 ancilla qubit.

    Basis ordering:
      |x>|y>  → index = (x << 1) | y
    """
    dim = 2 ** (n + 1)
    U = np.zeros((dim, dim), dtype=complex)

    print("
[Oracle Construction]")
    for x in range(2**n):
        fx = int(f(x)) & 1
        print(f"  f({format(x, f'0{n}b')}) = {fx}")
        for y in (0, 1):
            in_idx  = (x << 1) | y
            out_idx = (x << 1) | (y ^ fx)
            U[out_idx, in_idx] = 1.0

    return U
