Deutsch-Jozsa Algorithm

Exponential Quantum Speedup for Function Classification

The Problem

Given a function f: {0,1}ⁿ → {0,1} that is promised to be either constant (same output for all inputs) or balanced (outputs 0 for exactly half the inputs and 1 for the other half), determine which type it is with certainty.

Classical Approach

Must check up to 2ⁿ⁻¹ + 1 inputs in the worst case. For n=10 qubits: up to 513 queries!

Why? After checking half the inputs and getting the same answer, you still don't know if it's constant or balanced.

Quantum Approach

Needs only 1 query to the oracle! Exponential speedup: O(2ⁿ) → O(1)

Uses superposition to query all inputs simultaneously and interference to extract the answer.

Algorithm Steps

1 Initialize: Start with |0⟩⊗ⁿ|1⟩ (n input qubits in |0⟩, one ancilla in |1⟩)
2 Apply Hadamard to all qubits: Creates superposition of all 2ⁿ inputs and puts ancilla in |-⟩
3 Apply Oracle Uf: Phase kickback adds (-1)^f(x) to each input state
4 Apply Hadamard to input qubits: Interference amplifies or cancels amplitudes
5 Measure input qubits: If all zeros → CONSTANT, otherwise → BALANCED

Why It Works: The Math

After Step 2 (Hadamard on all):

|ψ₂⟩ = 1/√2ⁿ Σₓ |x⟩ ⊗ |-⟩

After Step 3 (Oracle with phase kickback):

|ψ₃⟩ = 1/√2ⁿ Σₓ (-1)f(x) |x⟩ ⊗ |-⟩

After Step 4 (Hadamard on inputs):

Amplitude of |0⟩⊗ⁿ = 1/2ⁿ Σₓ (-1)f(x)

Key insight:

  • If f is constant: All terms have same sign → sum = ±1 → P(|0⟩⊗ⁿ) = 1
  • If f is balanced: Half +1, half -1 → sum = 0 → P(|0⟩⊗ⁿ) = 0

def deutsch_jozsa(n, f):
    """
    Run Deutsch–Jozsa algorithm for n input qubits.
    Prints intermediate states for learning.
    """

    print("
" + "=" * 65)
    print(f"Running Deutsch–Jozsa for n = {n}")
    print("=" * 65)

    dim = 2 ** (n + 1)

    # ---------------------------------------------------
    # Step 1: Initialize |0^n>|1>
    # ---------------------------------------------------
    state = np.zeros(dim, dtype=complex)
    state[1] = 1.0  # |x=0>|y=1>

    print("
Step 1: Initial state |0...0>|1>")
    print(state)

    # ---------------------------------------------------
    # Step 2: Apply H on all qubits
    # Result: |+...+>|->
    # ---------------------------------------------------
    print("
Step 2: Apply H^{⊗(n+1)}")
    state = H_n(n + 1) @ state
    print("State after Hadamards:")
    print(state)

    # ---------------------------------------------------
    # Step 3: Apply oracle U_f
    # Phase kickback occurs here
    # ---------------------------------------------------
    print("
Step 3: Apply oracle U_f")
    U = oracle_Uf(n, f)
    state = U @ state
    print("State after oracle:")
    print(state)

    # ---------------------------------------------------
    # Step 4: Apply H^{⊗n} on input register only
    # ---------------------------------------------------
    print("
Step 4: Apply H^{⊗n} on input qubits")
    H_input = kron_all([H]*n + [I])
    state = H_input @ state
    print("Final state:")
    print(state)

    # ---------------------------------------------------
    # Step 5: Measure input register probabilities
    # ---------------------------------------------------
    print("
Step 5: Measure input register (ignore ancilla)")
    probs = {}
    for x in range(2**n):
        amp0 = state[(x << 1) | 0]
        amp1 = state[(x << 1) | 1]
        p = abs(amp0)**2 + abs(amp1)**2
        if p > 1e-10:
            probs[format(x, f"0{n}b")] = p

    for k, v in probs.items():
        print(f"  P(|{k}>) = {v:.6f}")

    # ---------------------------------------------------
    # Step 6: Deutsch–Jozsa decision
    # ---------------------------------------------------
    if probs.get("0"*n, 0.0) > 1 - 1e-9:
        decision = "CONSTANT"
    else:
        decision = "BALANCED"

    print("
Deutsch–Jozsa Decision:", decision)
    return probs, decision
